# DON'ACT 🤝

🚀 A smart donation management platform designed to connect donors, associations, and beneficiaries through a transparent and modern digital solution.

DON'ACT aims to simplify donation management, improve transparency, and facilitate solidarity actions by providing an intelligent platform that connects different actors involved in humanitarian initiatives.

---

# ✨ Features

## 🤝 Donation Management

* Create and manage donation campaigns
* Allow donors to contribute to humanitarian projects
* Track donations and contribution history
* Improve transparency between donors and associations

## 🏢 Association Management

* Association registration and profile management
* Verification of association legal status
* Manage donation requests and campaigns
* Monitor received contributions

## 👤 Beneficiary Management

* Create beneficiary profiles
* Submit donation requests
* Priority management based on urgency
* Track request status

## 🔐 Authentication & Role Management

* Secure authentication system
* Role-based access control:

  * Donors
  * Associations
  * Beneficiaries
  * Administrators

## 🤖 Artificial Intelligence Features

* AI-powered chatbot assistance
* Automatic feedback generation based on user ratings
* Multilingual AI feedback generation
* Intelligent evaluation of user experience

## 🌍 Localization & Accessibility

* Multi-language support:

  * Arabic
  * French
  * English
* User-friendly interface adapted for different languages

## 📍 Smart Location Features

* Google Maps API integration
* Display associations on an interactive map
* Help donors find nearby organizations

## 📊 Administration Dashboard

* Manage users and roles
* Verify associations
* Manage categories
* View donation statistics
* Export reports in PDF and Excel formats

## 💳 Payment Integration

* Secure online donations with Stripe
* Manage donation transactions

# 🚀 Getting Started

## Prerequisites

Make sure you have installed:

* Node.js
* npm package manager
* MySQL database

---

# 📥 Installation

## 1. Clone the repository

```bash
git clone <repository-url>
cd DON-ACT
```

---

# ⚙️ Backend Setup

Navigate to the backend folder:

```bash
cd backend
```

Install dependencies:

```bash
npm install
```

Start the backend server:

```bash
node server.js
```

The backend API will start on the configured port.

---

# 💻 Frontend Setup

Open another terminal:

```bash
cd frontend
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

The frontend application will be available through the Vite development URL.
